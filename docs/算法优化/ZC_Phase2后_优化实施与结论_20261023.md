## 4. 分方向结论

### P1 — dualgate + REJ（必做，已完成）

- **有效**。与历史 M1 量级一致：跨天 mean **−66%**。
- REJ=2.0 **必要**：关 REJ 时 081533 mean 仅到 0.13。
- 同天/大楼：无收益也无伤（terr/rerr 持平）。
- med/p90 平移几乎不动 → 符合「吃尾部」预期。
- **建议**：Phase2 ENU 评测协议把 `SIM3_AGG=dualgate SIM3_REJ_M=2.0` 列为默认之一（仍保留 bm3 对照列）。

### P2 — EKF（必做，已完成三场景）

- **有效**，在 P1 之上仍能再削 mean/p90；对 bm3 残差尾部帮助更大。
- **口径**：运动 = 离线 GTΔ；上真机前必须换成 `/odom` 或轮速并重测。
- 0923 EKF 后 cross p90 可到 ~2.6 cm（脚本口径）——仍 **不** 当作产品达标声明（尺子底噪 + 离线运动）。

### P3 — K=10（冒烟）

- **当前证据不支持**用 K=10 替代 K=5+dualgate：更慢，bm3 更差，dg 无额外 mean 红利且 cross p90 变差。
- 未验证：紧半径 / 两两一致性 / zcOnlyENU 专用 cands 离线扫。

### P4–P7

- **已完成实测**，专文：[`ZC_Phase2后_优化实施与结论_P4-P7_20261023.md`](./ZC_Phase2后_优化实施与结论_P4-P7_20261023.md)
- **P4** 邻域 med/clamp/blend：相对 dg+REJ **劣化**（081533 mean 0.067→≥0.069）；不并入。
- **P5** `APPLY_OFF`：绝对 off 炸 terr；Δoff 伤 rerr（081533 0.76→1.82 p90）。XFeat 草坪仍应用 `base` 非 `rc`；Reloc3r 基线门控无净增益。保持 off/门控关。
- **P6** 基线分桶 + 收紧过滤：尾部非窄带集中；收紧过滤更差。不重训。
- **P7** `/data`~25G 空闲跳过短续训；`p7_loss_weight_smoke.py` 5-step OK。

## 5. 对验收口径的客观差距

目标记忆：沿轨 &lt;10 cm / 横向 &lt;3 cm / 角 &lt;0.2°（ENU）。

| 指标 | 最优实测（本轮） | 差距 |
| :--- | :--- | :--- |
| along med | 三场景约 **2.6–3.3 cm**（dg+REJ） | med 已贴/优于 10 cm；along **p90** 仍约 **8–9 cm** |
| along p90 | ~8.2–8.6 cm | 距「p90&lt;10 cm」近，但需固定协议 |
| cross med | ~1.1–2.1 cm | med 好看；**不能**代表达标 |
| cross **p90** | 仍约 **5.7 / 6.1 / 3.2 cm**（dg+REJ probe） | **未达 3 cm**；081533/062224 明显超 |
| rerr med | ~0.21–0.36° | 部分场景 med 近 0.2°，p90 仍 **0.7–0.8°** |
| rerr p90 | ~0.73–0.79° | 距 0.2° 仍远；本轮未动 `off_rad`/交会角门控 |

**RTK/跨包 NN 底噪（约 15–20 cm 历史量级）仍可能硬挡 cross&lt;3 cm 产品口径。**

## 6. 建议的下一步（≤5）

1. **默认评测开关**：Phase2 ENU 协议增加 dualgate+REJ=2.0 列；文档与脚本对齐。
2. **在线运动模型**：用真 `/odom`（或轮速）替换 EKF 的 GTΔ，重跑三场景，再决定是否上车。
3. **P5/P4 本轮已否决默认**：保持 APPLY_OFF=0；勿无门控 rc 铺草坪；勿上朴素邻域平滑。
4. **下一优先**：相对边短窗位姿图（真 P4-hard）或产品侧多条件 db——仅当要继续压 cross p90 / 灾难帧。
5. **勿优先**：K=10 满推、满训/短续训（磁盘紧）、无门控几何 R、Δoff 旋入 R。

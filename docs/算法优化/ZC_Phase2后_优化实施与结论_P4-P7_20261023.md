## 2. P5 — 角度与航向：`off_rad` + 交会角/基线门控

### 2.1 `APPLY_OFF`（Phase2 ENU Reloc3r 实测）

代码：`reloc3r-grok-bot/eval_zc_sim3.py` 支持 `APPLY_OFF=1`。

| 模式 | 含义 | 081533 terr / rerr | 0923 terr / rerr | 062224 |
| :--- | :--- | :--- | :--- | :--- |
| **OFF（默认）** | Phase2 旁路，off 不入 R | 0.07/0.05/0.12 · **0.44/0.36/0.76** | 0.06/0.04/0.10 · **0.38/0.21/0.79** | 0.06/0.05/0.11 · 0.41/0.36/0.73 |
| 绝对 off(~93°) 旋入 | 误用；破坏运动平均 | terr **1.28**/… rerr 1.40 | terr **1.44** | terr **4.19** |
| **Δoff vs db** | 081533 −1.306°；0923 −0.553°；062224 −0.081° | terr 0.07/0.05/0.12 · **1.41/1.41/1.82** | 0.06/0.04/0.10 · **0.78/0.61/1.26** | 0.06/0.05/0.11 · 0.42/0.36/0.71 |

要点：
- `off_rad` 绝对值 ~90°+ 是安装角，**不是**评测可旋的小偏置；旋入会毁平移。
- 跨包 Δoff 旋入 query R 等价于给 eθ 加偏置 → **rerr 变差**，terr 不变。与 `eval_rtk_rescore` 注释一致：原始 eθ 中心≈0，勿强行 BIAS_CORRECT。
- **建议：保持 `APPLY_OFF=0` / `BIAS_CORRECT=0`。**

日志：`p5_apply_off_*.log`（绝对，反例）、`p5_apply_doff_v2_20261023_141933.log`（Δoff 正测）

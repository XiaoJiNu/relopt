## 1. M1 灾难尾部抑制（已实施，落生产）

实现 = 三级判据（`reloc3r/eval_zc_sim3.py` env `SIM3_AGG=dualgate`）：
1. **双锚**：候选推算位置中位数锚（bm3 原语义）与检索 top-1 锚一致（≤1 m）→ 用 top-1 锚子集（r=3 m）；
2. **时序连续门**：不一致时，若 top-1 锚聚合结果与"上帧位置+运动增量"差 ≤3 m 仍用 top-1，否则回退中位数锚；
3. **跳变拒绝**（方案"方法3-lite"）：最终聚合结果与预测位差 >2 m 时冻结为预测位（`SIM3_REJ_M=2.0`）。

离线扫定参（`relopt/scripts/gt_probes/agg_sweep_m1.py`，K=10 dump 零 GPU）→ 生产 eval 逐位复现 → RTK 口径重评三重一致。运动增量离线用 GT 帧差（上真机换 /odom，一行改）。

**新发现（M1 适用边界）**：官方权重（未微调）上 dualgate 反而大幅有害（跨天 mean 0.588→1.376）——top-1 锚假设"检索第一名的几何最可信"只在域适配后的权重下成立。**dg 只能配微调臂上生产，官方臂一律 bm3。** 0923 新臂上 dg 亦微劣（+0.01 m），场景相关性存在但幅度小。

## 2. M2 GT 升级（已实施，零训练）

- `relopt/scripts/gt_probes/build_rtk_gt.py`：逐包 `enu = w·(p_map + R_yaw·v) + o` 拟合（与归档 gt_analysis5 数字逐位一致），产出 `cache/rtk_gt_<bag>.npz`（5 包全部，含逐帧 fidx 对齐的相机 ENU 真值 + 双天线朝向偏置 off）。杆臂拟合把 /map-vs-RTK 绝对残差压到 4.9–7.1 cm p50（验收 <8 cm ✅）。
- `relopt/scripts/gt_probes/eval_rtk_rescore.py`：预测锚定 db 包 ENU、真值取 query 包 RTK 锚定值，朝向偏置可选扣（`BIAS_CORRECT=1`）；输出含沿/跨轨分量。

RTK 口径结果（旧臂 ft，bm3→dg）：同天 0.071→**0.063**、跨天 0.236→**0.076**、0923 0.101→0.100 m。
三目标判定（dg 臂）：沿轨 mean 4.3/5.5/8.6 cm ✅<10；跨轨 mean 3.2/3.9/3.4 cm、med 1.9–2.5 cm（RTK 硬底 5–7 cm 之下无法确证 3 cm，D2 原样保留）；eθ med 0.19/0.25/0.17°。

**朝向结论（修正方案 §0 的表述）**：官方权重跨天**带符号** eθ med = **+1.90°**（n=150 探针）——跨包基准差确实 1:1 进指标；但旧/新微调臂 raw 仅 +0.09°，即**微调把训练包里出现的基准差吸进了回归**（经 pose.txt 标签记忆）。部署推论：模型只对"训练见过的 db↔query 包对"保持这个吸收，新第三包无此保证——角度口径量产前应按 RTK+去偏重验，不能引用 raw 数字。双天线偏置实测差 0.081/1.306/0.553° 存档于 json `_note`。

## 3. M3 检索统一重训 + M4 遗忘（已实施，单臂合训）

臂 = `checkpoints/zc_finetune_M_mix50_lr5e6`（PAIRSET=M 用 zcM/zc9M 对 + ND=12000 即 MD 混 50% + lr 5e-6，D1/D4 建议的合并执行），30 ep 实跑 ~21 h（16:20 启动→04:30 完成，看门狗无挂死），训后自动链完成遗忘检查+双口径回测（`reloc3r/scripts/m3m4_auto.sh`）。

遗忘（MegaDepth-1500 后半 200 对，gate ≤1.72°）：官方 1.561 → ft 2.053 → mix50 1.976 → **本臂 1.773**（rerr 0.573→0.941→0.894→0.838）。降 lr 是本步主贡献（对比 mix50 单变量 lr）。**仍差 0.053° 未过线**——混合比、降 lr 两条零改路至此全部用尽，方案 §4 M4 的下一条 = LoRA/adapter（需改 train.py，未实施，等决策）。

域适配（vs 旧臂，同奇子集，bm3 口径 ep mean）：同天 0.0747→0.0748、跨天 0.2403→0.2166、0923 0.1046→0.1038——**几乎不动**（方案 §3.2 预判"标签同源、收益待测"兑现）。med 微劣化 ~4 mm；p90 持平或更好（M3 验收"不劣化"过线）。负增益点：0923 rerr p90 0.545→0.986°（角度尾部明显变差）。结论：**M3 单独看无留存价值**；它与新臂的遗忘改善绑定在同一模型里，若要"遗忘最好 + 0923 角度不退"需再拆臂（lr5e-6 + NetVLAD 对，~21 h），未做。

## 3. 可尝试且有希望的方向（按优先级）

每条格式：**动机 / 改什么 / 期望吃掉哪块误差 / 风险与验收 / 与 Phase1/2 关系**。

---

### P1 — 在 Phase2 ENU 权重上复开 dualgate（+REJ）【时序轻量 + 聚合】

- **动机**：Phase2 自测固定 `SIM3_BM3=1`、**未设** `SIM3_AGG=dualgate`。实施报告在旧微调臂上证明 dualgate+rej 跨天 ep_mean **0.240→0.080**，灾难帧 9→4；081533 的 Phase2 terr mean **0.20** 与历史「尾部主导 mean」同型。
- **改什么**：
  1. 最短路径：`POSE_TAG=enu SIM3_K=5 SIM3_AGG=dualgate SIM3_REJ_M=2.0` + Phase2 `checkpoint-best`，三场景复评；
  2. 或先 `dump_cands`（K=10，zcOnlyENU）→ `agg_sweep_m1.py` 零 GPU 定参 → 再落 eval；
  3. 用 `probe_along_cross_phase2_enu.py`（或改读新 npz）重算 along/cross。
- **期望吃掉**：081533 **mean** 与少数大跳变；连带压 **cross/along 的 mean 与部分 p90**（尾部帧）。med 可能几乎不动——这正常。
- **风险与验收**：官方臂上 dualgate 曾有害（实施报告「新发现」）→ **只配微调臂**；0923 上 dg 历史上微劣 → 三场景分列，不因一个场景关全局。验收：相对 Phase2 bm3 基线，跨天 terr mean / &gt;0.5 m 帧数下降；along/cross **p90** 不劣化或下降；**仍不宣称 cross&lt;3cm**。
- **与 Phase1/2**：Phase1/2 解决域适配与尺子；本项兑现 **M1 在新尺子+新权重上的红利**，零改训练。

---

### P2 — 时序约束：EKF / 短滑窗滤波接 Phase2 ENU 观测【时序】

- **动机**：量产路线与实施记录已证：单帧过滤器压不干净 look-alike；**EKF 融合曾综合分登顶（0.819）**，靠时序连续性 + gate3 吃尾部。Phase2 输出仍是逐帧独立。
- **改什么**：
  1. 用 `eval_zc_sim3_cache.py`（或现有 dump）导出 Phase2 ENU 下逐帧 `pred` 4×4；
  2. 接 `ekf_fuse.py`：运动模型先用 GT 增量+噪声（离线口径，与文档一致），观测用 Reloc3r ENU 位姿；可选再加 XFeat 平移观测；
  3. 进阶：真实 `/odom` 或轮速（上车前做漂移检查）；滑窗可先做「常速度 + 门控」再上完整 EKF。
- **期望吃掉**：look-alike 翻转、沿轨尺度漂移尖峰、**cross/along p90 尾部**；平滑帧间抖动。
- **风险与验收**：离线 GT 增量偏乐观 → 报告必须标「离线运动模型」；gate 过紧会冻住正确大机动。验收：相对 P1 单帧结果，ep/along/cross 的 **p90 与 mean** 下降；eθ 尾部不恶化；延迟仍满足在线预算（缓存路径已有）。
- **与 Phase1/2**：不改权重；把 Phase2 单帧观测送进**已验证的时序壳**。

---

### P3 — 候选池扩容 + 几何一致性（K=10、紧半径、两两一致）【空间/聚合】

- **动机**：优化方案 §2.1：oracle best-3-of-5 可达 ep med≈**0.03 m** 量级 → **池里常有好候选，bm3 没选中**。K=10 + 更紧一致性曾在 anchor 扫里帮过跨天。
- **改什么**：在 P1 定参扫中纳入 `K10_anchor1_r1.5` 等；可选两两相对位姿一致（RANSAC/簇）再 motion averaging；与 dualgate 叠加而非替代。
- **期望吃掉**：错误簇占多数时的中位数锚失效；进一步压 **灾难帧与 cross p90**。
- **风险与验收**：K↑ 增推理（可用 encoder 缓存摊薄）；过紧半径在弯道/稀疏 db 可能饿死好候选。验收：&gt;0.5 m 帧数、跨天 mean；relpose 时延可接受。
- **与 Phase1/2**：纯推理侧；依赖 Phase2 权重下的新 cands dump。

---

### P4 — 空间约束：短窗 SE(3)/Sim(3) 图或邻域一致性【空间】

- **动机**：dualgate 只用「上一帧预测位」；草坪环线存在**空间 look-alike**（相距数十米外观近）。把「相邻 query 帧 + 对应 db 锚」做成短窗位姿图，用相对边（Reloc3r）+ 绝对锚（db ENU）做局部优化，比单帧投票更稳。
- **改什么**（由易到难）：
  1. **邻域一致性**：当前帧解与 ±N 帧解在 ENU 下应近似刚体/匀速，不一致则降权或回退；
  2. **短窗 SE(3) 平滑**（5–15 帧）：边 = 帧间 relpose 或 odom，节点锚定到选中的 db pose；
  3. **可选**：db 子图局部 Sim(3)/BA（优化方案 M2「联合 BA」的轻量版，先不做全包闭合）。
- **期望吃掉**：空间歧义造成的横向跳变、环线重复带上的错误簇；辅助压 **cross p90**。
- **风险与验收**：实现量高于 P1/P2；窗过长会抹掉真转弯。验收：先在 081533 灾难帧邻域做 case study，再全量 six 列；对比 P2 EKF，看是否多吃「非时序连续的空间歧义」。
- **与 Phase1/2**：建立在 ENU 绝对坐标已对齐的前提下才有意义（Phase2 已提供）。

---

### P5 — 角度与航向：交会角门控几何解 + `off_rad` 开关【其它 / 角度】

- **动机**：Phase2 0923 rerr p90≈**0.79°**；Phase2 §6 明示 `off_rad` 未入 R。实施记录：草坪 recoverPose **有害**、大楼 **med −41%** → 必须按交会角/db 间距门控。
- **改什么**：
  1. env 开关：组装 ENU 时可选 `R_z(off)` 旋入，双天线绝对航向对齐后重评 eθ；
  2. 移植 `eval_zc_xfeat_rc` 的 rc 思路到 Reloc3r 聚合：仅当候选 db 间距/基线足够大时融合几何 R。
- **期望吃掉**：eθ 的系统性偏置与大楼旋转尾部。
- **风险与验收**：乱开 off 可能搅相对训练标签一致性 → **仅评测旁路先试**；草坪禁无无门控 rc。验收：eθ med/p90；平移六列不劣化。
- **与 Phase1/2**：补 Phase2 未决项 4/5；不替代 P1 尾部抑制。

---

### P6 — 数据 / 配对：难例挖掘、基线带、多条件 db【其它】

- **动机**：量产路线 §3.4：跨天老化靠 **db 条件覆盖**；检索 hit 已高，瓶颈在 look-alike 判别。讨论结论：一场景一 db，query 可跨天。
- **改什么**：同向多条件 db（pre/post-mow）；制对时加大「易混淆负对」或收紧/细分基线带（现 0.15–10 m）；db 抽帧加密仅当产品要压位置地板。
- **期望吃掉**：跨天错误簇、检索歧义 → 间接降灾难帧。
- **风险与验收**：要补采/重制对/可能重训，成本高于 P1–P3。验收：MegaLoc 混淆对比例、灾难帧数；**先做统计探针再决定是否重训**。
- **与 Phase1/2**：Phase2 相对 GT 已干净；此项改的是**候选分布与地图覆盖**，不是再换尺子。

---

### P7 — 训练侧小改：损失加权 / 短续训扫 LR（靠后）【其它】

- **动机**：Phase2 best val med≈0.0808；0923 角度仍弱；相对 GT 与 map 几乎同构 → **再训一轮期望有限**。
- **改什么**：仅在 P1–P3 仍留下「普遍 med 不够」时：沿轨/横向方向损失加权、或短续训扫 LR/epoch；LoRA 仅当产品要过遗忘门槛。
- **期望吃掉**：轻微域内 med/角度；**不应指望单独解决 cross p90**。
- **风险与验收**：易抖动基线；须固定 ENU 评测协议对比 Phase2 best。
- **与 Phase1/2**：在 Phase2 ckpt 上续训，避免从官方重开。
